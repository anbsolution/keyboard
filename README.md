# Voice Keyboard

Android IME keyboard project.

## Version 1.0.2 (JVM target fix)
- Android Input Method Service (IME)
- English QWERTY input
- Hindi Devanagari key labels and direct Unicode input
- Correct symbol-mode output
- Shift, backspace, space, enter, number/symbol toggle
- Keyboard enable/select screen
- Java and Kotlin compilation both target JVM 17
- GitHub Actions unit tests and debug APK artifact

## Voice recognition status
The microphone icon is a Phase 2 placeholder. This release does not perform speech recognition. No microphone or internet permission is requested.

## Build
GitHub Actions runs unit tests and assembles a debug APK. Download the APK from a successful workflow run's Artifacts section.
